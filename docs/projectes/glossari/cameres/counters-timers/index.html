Counters & Timers

Amb els comptadors i temporitzadors dels features GenICam de les càmeres es poden fer algunes operacions complexes de control de llums, retard de captures, etc. Per exemple:

  • Activar 2 flashos diferents, de forma alternada.
  • Capturar amb una càmera lineal mentre es detecta una fotocèlula, amb un retard quan es deixa de detectar

De totes maneres, totes les configuracions que utilitzen comptadors i temporitzadors seran difícils. Aquests features no estan gaire ben pensats.

Configuració seqüència flash​

En el projecte de Eversia, on es feia servir una càmera Basler, feia falta fer 3 fotos seguides amb Frame Burst (una sola senyal de trigger, imatges separades uns 20 milisegons): la primera i última foto amb barra LED, la del mig amb backlight. A la pràctica es capturaven 4 imatges enlloc de 3, per limitacions de les funcionalitats de Counter de la càmera.

El principi de funcionament són dos comptadors que s'activen amb el flanc de pujada d'una imatge i es saturen (completen el comptatge) amb el flanc de baixada de la imatge. El reset dels comptadors es fa amb el comptador contrari, i per tal de fer el desfasament inicial es satura manualment el segon comptador.

tip

Si la càmera només disposa de dues sortides (outputs) normalment només tindrà 2 comptadors, i per tant com a màxim podrem controlar 2 llum diferents.

La configuració de càmera per aconseguir això és la següent:

// Trigger, i ràfaga de 4 imatges
Cameras.camera1.writeEnumSymbolic("TriggerSelector", "FrameBurstStart");
Cameras.camera1.writeEnumSymbolic("TriggerMode", "On");
Cameras.camera1.writeInteger("AcquisitionBurstFrameCount", 4);

// Comptador 1 - Trigger barra LED (darkfield)
Cameras.camera1.writeEnumSymbolic("CounterSelector", "Counter1");
Cameras.camera1.writeEnumSymbolic("CounterTriggerSource", "ExposureActive");
Cameras.camera1.writeEnumSymbolic("CounterTriggerActivation", "RisingEdge"); // S'activa comptador al primer pols
Cameras.camera1.writeEnumSymbolic("CounterEventSource", "ExposureActive");
Cameras.camera1.writeEnumSymbolic("CounterEventActivation", "FallingEdge");
Cameras.camera1.writeEnumSymbolic("CounterResetSource", "Counter2End");
Cameras.camera1.writeInteger("CounterDuration", 1); // Un pols

// Saturem el segon comptador (status=completed) per tal que vagi desfasat respecte del primer
Cameras.camera1.writeEnumSymbolic("CounterSelector", "Counter2");
Cameras.camera1.writeEnumSymbolic("CounterTriggerSource", "SoftwareSignal1");
Cameras.camera1.writeEnumSymbolic("CounterEventSource", "SoftwareSignal1");
Cameras.camera1.executeCommand("SoftwareSignalPulse");
Cameras.camera1.executeCommand("SoftwareSignalPulse");

// Comptador 2 - Trigger backlight
Cameras.camera1.writeEnumSymbolic("CounterSelector", "Counter2");
Cameras.camera1.writeEnumSymbolic("CounterTriggerSource", "ExposureActive");
Cameras.camera1.writeEnumSymbolic("CounterTriggerActivation", "RisingEdge"); // S'activa al finalizar el primer comptador
Cameras.camera1.writeEnumSymbolic("CounterEventSource", "ExposureActive");
Cameras.camera1.writeEnumSymbolic("CounterEventActivation", "FallingEdge");
Cameras.camera1.writeEnumSymbolic("CounterResetSource", "Counter1End"); // Fer reset aquí no es necessari, reset manual al rebre imatges
Cameras.camera1.writeInteger("CounterDuration", 1); // Un pols

// Line2: backlight
Cameras.camera1.writeEnumSymbolic("LineSelector", "Line2");
Cameras.camera1.writeEnumSymbolic("LineMode", "Output");
Cameras.camera1.writeEnumSymbolic("LineSource", "Counter2Active");
Cameras.camera1.writeBoolean("LineInverter", true);

// Line3: barra LED (darkfield)
Cameras.camera1.writeEnumSymbolic("LineSelector", "Line3");
Cameras.camera1.writeEnumSymbolic("LineMode", "Output");
Cameras.camera1.writeEnumSymbolic("LineSource", "Counter1Active");
Cameras.camera1.writeBoolean("LineInverter", true);

També s'ha vist que és important assegurar que es treuen les 4 imatges de la ràfaga (està garantit que n'hi haurà 4), per tal d'evitar desincronitzacions. També s'ha vist que és important no fer clearOutputBuffer() entre ràfagues, perquè pot coinicidir que es fa just en el moment que es reben imatges i provocar una desincronització. És millor esperar la 4a imatge i extreure-la del buffer. La seqüència d'adquisició d'imatges ha de ser similar a aquesta:

Cameras.camera1.waitImage(-1);
var elapsedTime = time();
var image1 = Cameras.camera1.getImage();
var timestamp1 = image1.timestamp;
images.push(image1);

// NO esperamos nueva imagen
Cameras.camera1.waitImage(-1);
elapsedTime = time() - elapsedTime;
var image2 = Cameras.camera1.getImage();
var timestamp2 = image2.timestamp;
images.push(image2);

Cameras.camera1.waitImage(-1);
elapsedTime = time() - elapsedTime;
var image3 = Cameras.camera1.getImage();
var timestamp3 = image3.timestamp;
images.push(image3);

Cameras.camera1.waitImage(-1);
var image4 = Cameras.camera1.getImage(); // Aquesta imatge no s'utilitzava, però és important treure-la per evitar desincronitzacions
// Cameras.camera1.clearOutputBuffer(); -> No utilitzar

Configuració Teledyne Line Lite (càmera lineal)​

En el projecte de IFS - Quesos el Pastor 

// S'ha d'invertir la senyal que rebem de la fotocèlula
Cameras.lineal.writeEnumSymbolic("LineSelector", "Line3");
Cameras.lineal.writeBoolean("LineInverter", true);

// Es captura imatge (línies) mentre Counter1 estigui "Active"
Cameras.lineal.writeEnumSymbolic("AcquisitionMode", "Continuous");
Cameras.lineal.writeEnumSymbolic("TriggerSelector", "FrameStart");
Cameras.lineal.writeEnumSymbolic("TriggerMode", "Off");
Cameras.lineal.writeEnumSymbolic("TriggerSelector", "FrameActive");
Cameras.lineal.writeEnumSymbolic("TriggerMode", "On");
Cameras.lineal.writeEnumSymbolic("TriggerSource", "Counter1Active");

// Configurem Timer1 per activar-se quan es deixa de detectar la fotocèlula
Cameras.lineal.writeEnumSymbolic("timerSelector", "Timer1");
Cameras.lineal.writeEnumSymbolic("timerStartSource", "Line3");
// Cameras.lineal.writeEnumSymbolic("timerStartLineActivation", "RisingEdge"); // Això no es pot escriure (sembla un bug de Teledyne), per això hem invertit Line3
Cameras.lineal.writeInteger("timerDuration", 400 * 1000); // Microseconds
Cameras.lineal.writeEnumSymbolic("timerMode", "Active");

// Utilitzem el comptador com a condició lògica OR entre la detecció de la fotocèlula i el temporitzador
Cameras.lineal.writeEnumSymbolic("counterSelector", "Counter1");
Cameras.lineal.writeEnumSymbolic("counterStartSource", "Line3");
Cameras.lineal.writeEnumSymbolic("counterStartLineActivation", "FallingEdge");
Cameras.lineal.writeEnumSymbolic("counterIncrementalSource", "Timer1End");
Cameras.lineal.writeEnumSymbolic("counterResetSource", "Timer1End");
Cameras.lineal.writeInteger("counterDuration", 1);
Cameras.lineal.writeEnumSymbolic("counterMode", "Active");
