Introducció

La llibreria treballa amb coordenades i càlculs en coma flotant (float, i de vegades double per als càlculs intermedis). Entendre com funcionen els nombres en coma flotant és essencial per escriure codi geomètric correcte: moltes operacions que semblen trivials (comparar dos punts, saber si tres punts són col·lineals, si dues rectes són paral·leles) fallen si es fan de manera ingènua.

Aquesta secció explica:

  • El problema: per què els càlculs en coma flotant tenen error i com creix.
  • Els tipus d'error i el cas més perillós, la cancel·lació catastròfica.
  • La solució: quan comparar amb igualtat exacta i quan cal fer servir toleràncies.
  • Les tècniques per fer-ho correctament i de manera reutilitzable.

Un nombre finit de bits​

Un float de 32 bits (IEEE 754) només té 24 bits de significand. Això vol dir que no pot representar tots els nombres reals, només un subconjunt finit. La majoria de valors decimals (fins i tot 0.1) no tenen representació exacta.

Aproximació al nombre més proper​

Quan un valor no es pot representar exactament, no es trunca: s'arrodoneix al nombre representable més proper. IEEE 754 garanteix que cada operació aritmètica bàsica (+, -, *, /) té un error màxim de mig ULP (la meitat de la distància entre dos valors representables consecutius).

L'error d'una sola operació és minúscul. El problema apareix quan s'acumula al llarg d'una cadena de càlculs, o quan una resta el fa explotar (cancel·lació catastròfica, vegeu Tipus d'error).

ULP: la distància entre dos floats consecutius​

Un ULP (Unit in the Last Place) és la distància entre un float i el següent valor representable. No és constant: els floats estan més separats a mesura que creix la magnitud. A prop de 0 són molt densos; a magnituds grans, molt espaiats.

MagnitudULP (separació)Dígits decimals útils
1~1.19e-77
1.000~6.10e-54-5
10.000~9.77e-4~3
20.000~1.95e-3~2-3
50.000~3.91e-3~2
65.536~7.81e-3~1-2
danger

A magnitud 50.000 (habitual en coordenades de píxel d'imatges grans), dos float que difereixen en menys de ~0.004 són indistingibles. Per això les coordenades grans perden precisió i les comparacions ingènues fallen.

  • Bruce Dawson, "Comparing Floating Point Numbers, 2012 Edition".
