Eines

Veure els mòduls natius carregats (.dll o .so)​

Quan es treballa amb add-ons natius de Node.js, pot ser útil veure quines llibreries dinàmiques (.dll a Windows, .so a Linux) carrega el procés node.exe en execució. Això ajuda a diagnosticar problemes de versions incorrectes de llibreries o de rutes.

Windows​

Per veure els .dll carregats per un procés node.exe, executar la següent comanda a la línia de comandes (CMD) o PowerShell:

tasklist /m /fi "imagename eq node.exe"

Això mostrarà els mòduls carregats per cada PID de node.exe.

Linux​

A Linux es pot fer servir lsof per llistar els fitxers oberts per un procés. Primer, trobar el PID de l'aplicació Node.js:

pgrep node

Després, fer servir el PID amb lsof per trobar els fitxers .so carregats (substituir <PID> pel de la comanda anterior):

lsof -p <PID> | grep .so

Comprovar si un binari és x64 o x86​

A Windows, fer servir l'eina dumpbin.exe, normalment inclosa a la carpeta de binaris del compilador MSVC, per exemple a C:\Program Files (x86)\Microsoft Visual Studio\2017\Community\VC\Tools\MSVC\14.25.28610\bin\Hostx64\x64. Executar la comanda ./dumpbin.exe /headers path-to-the-file.bin i es mostrarà la informació sobre la màquina de destí. Aquesta eina serveix per a DLL, LIB i EXE.

Comprovar les dependències d'una llibreria dinàmica​

A Windows, fer servir l'eina dumpbin.exe (mateixa ubicació que a l'apartat anterior) amb la comanda ./dumpbin.exe /dependents path-to-the-file.dll.

A Linux, fer servir la comanda ldd <path_to_so>.

Obtenir els objectes exportats d'una llibreria dinàmica​

A Windows, fer servir la comanda dumpbin /exports <path_to_dll>.

A Linux, fer servir la comanda nm -D <path_to_so>.

Executar CMake des de la línia de comandes​

Crear el build:

~/package $ mkdir build
~/package $ cd build
~/package/build $ cmake .. -D CMAKE_INSTALL_PREFIX="./install"

Compilar:

~/package/build $ cmake --build . --config Debug

Instal·lar:

~/package/build $ cmake --install . --config Debug
