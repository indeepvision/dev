Modals i popovers

Al VisionCloud hi ha modals (o popups) i popovers. Els modals ocupen tota la finestra i bloquegen la interacció amb la pàgina (enfosqueixen el fons i el deshabiliten), de manera que l'únic element amb el que es pot interactuar és el modal. Els popovers són més petits i no bloquegen la interacció amb la pàgina, de manera que es poden tenir diversos popovers oberts alhora.

Tipus de modals​

Pel VisionCloud hem definit una estandardització en dos tipus de modals, segons l'acció que facin, que determina alguns aspectes del disseny i de com es tanca el modal.

1. Action modal​

Modal que representa una única tasca amb un punt de decisió clar. Un cop l'usuari actua, la tasca es dona per finalitzada i el modal es tanca.

Exemples:​

  • Create dataset
  • Edit dataset
  • Create folder
  • Create project
  • Train model

Característiques:​

  • Peu amb parell de botons: Acció (ex. "Create", "Save") i Tancar (ex. "Cancel", "Close").
  • Es tanca automàticament en completar l'acció.
  • No té icona de tancament (X) disponible a la cantonada superior dreta, ja té el botó de "Tancar" al peu.

Marges:​

A més a més del marge exterior del modal (o popup) que ja es defineix a ID Styles i és de 30px (fins el 12/07/2026 havia estat de 36px), s'ha d'estandarditzar el marge entre el contingut i els botons inferiors a 24px, com s'indica en la imatge.

2. Utility modal​

Modal que dona suport a una activitat sense un punt de finalització concret. L'usuari hi pot fer una acció, moltes, o cap, i sortir quan vulgui.

Exemples:​

  • Add comments
  • Add tag
  • Version manager

Característiques:​

  • Sense peu amb botons d'acció (no hi ha una decisió única a confirmar).
  • L'usuari pot repetir accions internes (afegir comentaris, editar, etc.) sense que el modal es tanqui.
  • Es manté la icona de tancament (X) i el tancament per clic fora / tecla Esc, per garantir una sortida sempre accessible.
